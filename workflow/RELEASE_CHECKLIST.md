# Release checklist

## Selection and source

- [ ] Active ledgers, source registry, and oldest in-progress item reconciled.
- [ ] Canonical source identity, publication/upload time, baseline, and duplicate check passed.
- [ ] Raw evidence saved with retrieval metadata and hash.
- [ ] Every material claim has a primary/authoritative source or is explicitly attributed, qualified, or omitted.
- [ ] Source map and linear outline cover all material content without exceeding source limits.

## Content and language

- [ ] Hebrew master paragraphs passed direct source comparison and their individual Jev checks.
- [ ] Luna Max used for Hebrew-to-English translation, paragraph by paragraph, at maximum reasoning.
- [ ] English paragraph count/order and source coverage align with Hebrew master.
- [ ] Daf citations use Hebrew words and numerals in both editions.
- [ ] Hebrew-origin auditor checked every English paragraph; no unresolved Latin-script Hebrew-origin terms remain.
- [ ] Longer Hebrew quotations have immediate English translations.
- [ ] Spoken introductions and descriptions in both languages include article/source links, reciprocal show links, actual model names, AI-generated disclosure, and truthful human-review status.

## Audio, captions, artwork

- [ ] Each language uses the locked voice profile and recorded actual model/settings.
- [ ] Every audio chunk has a separate request record, transcript hash, usage/cost status, and Jev result.
- [ ] Final assembly count/order, hashes, codecs, sample rate, duration, file size, and transcript identity pass.
- [ ] Caption policy checked. If paused: no caption API, SRT/VTT file, validation, upload, or attachment occurred; status recorded.
- [ ] If captions were explicitly resumed: raw response preserved; each SRT format, text, timing, overlap, duration, encoding, size, attachment, and readback criterion passed.
- [ ] English and Hebrew episode covers are distinct, square, high-contrast, correctly spelled, and legible at phone size.
- [ ] Permanent show covers are unchanged.

## Publication and closure

- [ ] Active user authorization permits automatic publication after gates.
- [ ] English episode assigned to the correct show; saved title, description, and artwork reread.
- [ ] Hebrew episode assigned to the correct show; saved title, description, and artwork reread.
- [ ] Public live pages and playback verified for both languages.
- [ ] Live URLs and caption status recorded; `published_bilingual` written only after both readbacks pass.
- [ ] Audit totals, confidence range, usage, provider-estimated costs, and unavailable billing details reported.
- [ ] Any unresolved gate means keep the item `in_progress`; no release claim is made.
