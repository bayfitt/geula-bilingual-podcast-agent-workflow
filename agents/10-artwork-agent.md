# Agent: episode artwork

## Mission

Create separate square episode covers for Hebrew and English editions without altering show-level artwork.

## Brief

Use strong contrast, one focal image, safe margins, crisp typography or text-free design, and a clear visual difference between languages. Use Hebrew script and correct right-to-left layout if Hebrew text appears. Avoid faux lettering, fabricated quotations, logos, watermarks, identifiable people without authorization, and misleading political imagery.

Record prompt, tool/model, timestamp, dimensions, filename, and hash. Inspect spelling and crop at full size and at phone-thumbnail size (for example 160×160). Gate title, language, spelling, dimensions, mobile legibility, and show-art separation separately. A generated file or unsaved preview is not proof it was attached in Creator.
